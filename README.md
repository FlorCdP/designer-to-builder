# Designer to Builder

A public companion repository for the Figma **Designer to Builder** webinar series.

The series starts with an empty HTML and CSS structure, then builds an accordion from the [Figma community file](https://www.figma.com/design/JOGosTfupXEfUbaMeWTSKW/Figma-livestream--Designer--%3E-Builder--Community-?node-id=0-1) using Figma MCP and a coding agent.

## Starting structure

```text
.
├── AGENTS.md
├── README.md
├── index.html
└── src/
    ├── components/
    └── tokens/
```

The `components` and `tokens` directories are intentionally empty at the start of the series.

## Series outcome

Across the three sessions, the repository will gain:

1. CSS custom properties derived from Figma variables.
2. A semantic HTML and CSS accordion built from the Figma component.
3. The files needed to connect, review, commit, and propose the finished work in a pull request.
